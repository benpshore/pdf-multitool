# Local workbench API

The runnable contract is [openapi.yaml](../openapi.yaml), generated by
`uv run python scripts/generate_openapi.py`. Start `uv run pdf-multitool gui
--no-browser`; the browser and API use that server's loopback address. The fragment
token in the launch URL becomes the `X-PDF-Token` request header. The app removes
it from the visible URL. Never put it in query strings or public links.

`POST /api/files` takes raw bytes, `Content-Length`, and a URL-encoded `X-Filename`.
It returns an opaque file ID. Original bytes remain downloadable. Archives return
an array of extracted file records plus warnings; the original archive remains
available separately. The current session is temporary, single-user storage.

`POST /api/jobs` takes `{"operation":"tables","files":["file-id"],"options":{}}`
and returns HTTP 202 with a job ID. Poll `GET /api/jobs/{id}`. Results are published
only after every output of a particular input has passed validation. Failed parts
are removed. A batch can retain successful parts while another input fails.

States: `queued`, `running`, `completed`, `partial`, `failed`, `cancelled`.
Progress is a number from 0 to 1, based on completed input groups, not an invented
per-page percentage. `partial` also covers an inconclusive operation, such as no
table candidates or no recognized OCR text. Inspect `warnings`, `errors`, and
downloaded reports. A successful HTTP submission is not document completion.

`POST /api/jobs/{id}/cancel` with `{}` requests cancellation. Poll for a terminal
state; already completed parts remain downloadable. Downloads use the exact
same-origin `url` returned in a result record. `POST /api/bundles` with
`{"job":"job-id","format":"zip"}` (or `tar.gz`) packages the completed results.

HTTP 400 reports malformed requests, bad options, busy processing or exhausted
quotas, with a readable `error`. HTTP 401 is token failure, 403 is a Host/Origin
violation, and 404 is an unknown GET resource. Worker errors appear in the job's
terminal state, not as HTTP submission success claims. One queued/running job,
one shared engine gate, four HTTP connections, and session upload/output quotas
provide backpressure. Request bodies are capped at 32 KiB; a larger operation
configuration can use the CLI's bounded local input mechanisms.

## Additional engine operations

`GET /api/status` includes actual engine availability/version, limits, a machine
readable `capabilities.operations` contract and explicit feature gaps. The GUI and
CLI derive the new controls from these contracts. Unknown options, wrong types,
nonfinite numbers and out-of-range values are rejected before a worker starts.
Each non-creation operation runs once per selected file. `create` requires
`files: []`. PDF inputs accept a document `password`; credentials do not appear
in process arguments or result records. `pages` is one-based, for example `1,3-5`.

| Operation | Options (defaults shown) | Outputs and boundaries |
| --- | --- | --- |
| `svg` | `pages=""`, `text_mode="paths"` or `text`, `scale=1` (0.25–4) | SVG per selected page, preserving visible crop/rotation, plus a manifest with page geometry and hashes. Paths preserve glyph shapes; text references fonts without embedding them. Maximum 100 pages, 14,400-point side and 16 MiB/page. PDF interactions are not transferred. |
| `create` | `content=""`, `paper="a4"` or `letter`, `font_size=12`, `margin=36` | Paginated PDF using a bundled Unicode font. Missing glyphs fail. 20,000 characters and 100 pages maximum; no rich-text editor. |
| `paginate` | `pages=""`, `header=""`, `footer="Page {page} of {pages}"`, `font_size=10`, `margin=24` | New PDF with measured single-line headers/footers; unrotated pages only; overflow fails. Review overlap. |
| `tables` | `pages=""`, `strategy="lines"` or `text`, `tolerance=3` | JSON with source-page coordinates and candidate cells; CSV per table. CSV formula-leading strings are escaped; JSON retains original strings. No candidates gives partial. |
| `geometry` | `pages=""`, `dedupe_chars=false`, `tolerance=1` | JSON characters/words/bounds/text and TXT; optional duplicate-character suppression is reported and does not edit the PDF. |
| `optimize` | `compression_level=6` (1–9), `linearize=false` | pikepdf/qpdf lossless stream rewrite, new PDF and structural report. May increase size; not image downsampling or signature preservation. |
| `inspectpdf` | none | JSON syntax, metadata, outlines/form presence, document attachments and media-annotation inventory. No media execution or external fetching. |
| `attachments` | none | Document-level embedded files under generated `.bin` names, plus original names, sizes and SHA-256 in JSON. Annotation streams are only inventoried. |
| `deduplicate` | none | MuPDF object/stream deduplication, PDF and counts. Preserves pages and occurrences; does not deduplicate whole pages. |
| `render_native` | `pages=""`, `renderer="pymupdf"` or `ghostscript`, `dpi=144` | PNG per page, parsed before publication. Maximum 100 pages, 6,000-pixel side and 25 million pixels/page. |
| `ocr_tesseract` | `pages=""`, `language="eng"`, `dpi=200`, `psm=3` (3/6/11), `allow_rasterize=false` | Selected pages as searchable image PDF, TXT, per-page confidence TSV, JSON. Requires explicit rasterization acknowledgment and installed language data. Missing language fails; empty recognition is partial. |
| `deskew` | `pages=""`, `mode="auto"` or `manual`, `angle=0` (−10…10), `dpi=144`, `allow_rasterize=false` | Selected pages as image PDF and per-page angle report. Uncertain automatic results are partial. Preserves no native text layer and performs no curved-page dewarp. |

OCR/deskew are limited to 50 selected pages. All additional extractors have
character/table/attachment bounds in addition to process time, address-space,
file-size, descriptor and process limits. Every result is subject to shared
atomic publication, cancellation and session quotas. These limits do not provide
native filesystem isolation; see [security boundaries](SECURITY.md).

SVG downloads use `image/svg+xml` with attachment disposition, `nosniff`, and the
existing restrictive download CSP. The product does not execute or embed them as
live HTML. Engine-generated SVG is checked for passive elements, internal fragment
references, bounded embedded PNG/JPEG images and forbidden external resources.
This output check is not an arbitrary SVG upload sanitizer. See the
[SVG qualification](SVG_QUALIFICATION_20261015.md) for additional limits.

## Existing operation options retained

| Operations | Options | Outputs |
| --- | --- | --- |
| `merge`, `imagepdf` | `pages` for PDF merge, image `dpi=144`, optional PDF `password` | Combined PDF in input order; images do not imply OCR. |
| `split`, `rotate` | `pages`; split groups use `;`; `rotation=90/180/270`; `password` | New PDFs; original pages and files retained. |
| `render`, `text` | `pages`, render `dpi=120` (36–300), `password` | Poppler PNGs or layout TXT. Empty text is explicitly warned. |
| `html` | none | WeasyPrint inline HTML/CSS to PDF; all resource URLs blocked. |
| `compress` | `compress_profile=ebook` (`screen`, `printer`, `prepress`), `allow_lossy=true`, `password` | Ghostscript rewrite PDF with content-loss warning and size comparison. |
| `identify`, `rename` | `password` | Analysis JSON or conservatively named PDF copy. |
| `pdfhtml`, `markdown`, `textlayout` | `password`, `include_images` where supported, `skip_repeated_margins=false` for structured text/Markdown | HTML/Markdown/TXT, companion images and reports. No general semantic-order guarantee. |
| `clean`, `repaginate` | `password` | Structural PDF cleanup, or HTML-mediated reflow PDF. Reflow can alter layout. |
| `forms` | `password`, `fields` mapping or `create_fields` array, `flatten=false` | Inspection JSON, or verified filled/created/flattened PDF. See [forms](FORMS.md). |
| `signatures` | `password` | Signature-field report; no cryptographic validation/signing. |
| `redact` | `password`, `pages`, `redact_text`, `redact_boxes` | Native redacted PDF with post-save verification; see security limitations. |
| `unlock`, `protect` | `password`, protect `new_password` | Unencrypted or AES-256 protected copy. |
| `unpack`, `bundle` | unpack `max_expanded_bytes`/`max_files` (cannot exceed supervisor quotas); bundle `format=zip` | Bounded archive extraction or result package. GUI uses dedicated upload/bundle endpoints. |

The old options retain their existing validation behavior. They are not claimed
to have the strict additional-property schemas introduced for the new operations.
