02 / ACTION

Make it work

Combine selected PDFs and supported images in the order shown.

One password applies to all selected PDFs; different passwords in one job are not supported. Kept in memory for this operation only. Outputs are unencrypted unless you use Protect PDF.

AES-256. Use 8–127 UTF-8 bytes. Keep this password yourself.

Inspect field names, types, choices and radio export values. This does not change the PDF.

Removes matching native text and overlapping image pixels. Also removes metadata, attachments, links, annotations and form widgets. Image-only text needs rectangle redaction through the CLI.

Page numbers start at 1. Applied to each selected PDF.

For PDF rendering: pixel resolution. For image pages: physical page size; original pixels are not resampled.

Compression may reduce image quality and remove nonvisual content. Keep the original.

Docling and its models must be installed locally.

These tools use existing text layers. For scans, choose OCR with Tesseract or a configured Docling model.

Choose rows for known row-based records. The choice applies to every page; mixed layouts and empty cells still need review. Explicit ordering requires unrotated horizontal left-to-right text.

Off by default. Source page boundaries and uncertain text remain visible.
